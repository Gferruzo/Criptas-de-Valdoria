# Criptas de Valdoria

Juego cooperativo de mazmorras en el navegador, para jugar con hermanos y amigos. Sin fines de lucro.

**Jugar:** abre la página de GitHub Pages de este repositorio.

- Modo local: 1 jugador en celular, o hasta 2 en la misma PC con teclado o mandos.
- El progreso se guarda en el navegador. Usa el respaldo del menú para pasarlo a otro dispositivo.
- El modo en línea (hasta 4 jugadores) por ahora solo funciona en la versión publicada en Claude.

Todo el juego es un solo archivo: `index.html`.
